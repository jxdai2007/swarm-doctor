# Below One

Keep your swarm's R below one. One engine for everyday goal drift and directional outbreak containment; experimental results must distinguish synthetic development fixtures from live recordings.

## Development

Install Python 3.12 and uv. Run `uv sync --frozen`, `make test`, and `make check-env`. External dependency results live in `docs/first-hour-checks.md`. Copy `.env.example` to `.env` and complete `OPERATOR_TODO.md` before live experiments. Credentials are optional for offline development, required for scientific live evidence.

The approved build contract is `docs/plans/2026-10-03-0413-feat-below-one-plan.md`. Decisions live in `DECISIONS.md`; verification evidence in `GATES.md`. Preregistration lives in `experiments/preregistration.md` and must be committed before non-pilot live runs.

Experiment agents use disposable scenario workspaces. Builders never run experimental agents in this checkout. Engine unavailability denies actions; asynchronous steering is not a security boundary.
